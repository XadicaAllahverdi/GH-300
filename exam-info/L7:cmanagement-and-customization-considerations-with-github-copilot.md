<h2 id="contractual-protections">Contractual Protections</h2>
<h3 id="ip-indemnity">1. IP Indemnity</h3>
<p><strong>Available in:</strong></p>
<ul>
<li>GitHub Copilot Business</li>
<li>GitHub Copilot Enterprise</li>
</ul>
<p><strong>What it does:</strong><br>
IP indemnity provides legal protection if a Copilot suggestion is challenged as infringing on third-party intellectual property. In such cases, GitHub assumes legal responsibility.</p>
<p><strong>Important Condition:</strong><br>
For IP indemnity to apply, the <strong>“Matching public code” setting must be set to Block</strong>.</p>
<hr>
<h3 id="data-protection-agreement-dpa">2. Data Protection Agreement (DPA)</h3>
<p>GitHub provides a <strong>Data Protection Agreement</strong> that outlines:</p>
<ul>
<li>How user and organizational data is handled</li>
<li>Compliance with data privacy regulations (such as GDPR)</li>
<li>Security measures for protecting prompts and code context</li>
</ul>
<p>This agreement helps organizations meet legal and regulatory requirements for data handling.</p>
<hr>
<h3 id="github-copilot-trust-center">3. GitHub Copilot Trust Center</h3>
<p>The <strong>Copilot Trust Center</strong> is a centralized resource that provides transparency about:</p>
<ul>
<li>Security practices</li>
<li>Privacy controls</li>
<li>Compliance standards</li>
<li>Intellectual property safeguards</li>
</ul>
<p>It is a key reference for legal, security, and compliance teams.</p>
<hr>
<h2 id="filtering-out-matching-public-code">Filtering Out Matching Public Code</h2>
<h3 id="why-this-matters">Why This Matters</h3>
<p>Blocking matching public code helps:</p>
<ul>
<li>Maintain originality in your codebase</li>
<li>Reduce legal risk</li>
<li>Avoid introducing noncompliant or insecure code</li>
<li>Support IP indemnity eligibility</li>
</ul>
<p>Copilot detects suggestions that closely resemble publicly available code and can prevent them from being shown.</p>
<hr>
<h2 id="how-to-block-matching-public-code">How to Block Matching Public Code</h2>
<h3 id="step-by-step-configuration">Step-by-Step Configuration</h3>
<ol>
<li>On GitHub, select your <strong>profile photo</strong> (top-right corner)</li>
<li>Click <strong>Your enterprises</strong> or <strong>Your organizations</strong></li>
<li>Select the relevant <strong>enterprise or organization</strong></li>
<li>Go to <strong>Settings</strong></li>
<li>In the left sidebar, select <strong>Copilot</strong></li>
<li>Under <strong>Suggestions</strong>, find <strong>Matching public code</strong></li>
<li>Change the dropdown to <strong>Block</strong></li>
<li>Click <strong>Save</strong></li>
</ol>

<h2 id="what-are-content-exclusions">What Are Content Exclusions?</h2>
<p>Content exclusions allow administrators to define <strong>files, folders, or entire repositories</strong> that GitHub Copilot must ignore when generating:</p>
<ul>
<li>Code completion suggestions</li>
<li>Copilot Chat responses</li>
<li>Context-aware recommendations in other files</li>
</ul>
<p>This helps prevent sensitive or regulated data from influencing AI output.</p>
<hr>
<h2 id="configuration-options">Configuration Options</h2>
<h3 id="repository-level-configuration">Repository-Level Configuration</h3>
<ol>
<li>Go to the <strong>repository main page</strong></li>
<li>Select <strong>Settings</strong></li>
<li>In the sidebar, under <strong>Code &amp; automation</strong>, select <strong>Copilot</strong></li>
<li>In <strong>Repositories and paths to exclude</strong>, specify files or directories</li>
<li>Save your changes</li>
</ol>
<hr>
<h3 id="organization-level-configuration">Organization-Level Configuration</h3>
<ol>
<li>Select your <strong>profile photo</strong> (top-right corner)</li>
<li>Click <strong>Your organizations</strong></li>
<li>Choose the organization</li>
<li>Go to <strong>Settings</strong></li>
<li>Select <strong>Copilot &gt; Content exclusion</strong></li>
<li>Enter files, directories, or repositories to exclude</li>
<li>Save your changes</li>
</ol>
<blockquote>
<p><strong>Scope Note:</strong><br>
These settings apply to all users licensed under <strong>GitHub Copilot Business or Enterprise</strong> within that organization or repository.</p>
</blockquote>
<hr>
<h2 id="impact-on-code-suggestions">Impact on Code Suggestions</h2>
<p>When content is excluded:</p>
<ul>
<li>❌ Code completion is <strong>disabled</strong> in excluded files</li>
<li>❌ Excluded content does <strong>not inform suggestions</strong> in other files</li>
<li>❌ Excluded content does <strong>not inform Copilot Chat responses</strong></li>
</ul>

<h2 id="limitations-of-content-exclusions">Limitations of Content Exclusions</h2>
<h3 id="ide-limitations">1. IDE Limitations</h3>
<p>In some IDEs, exclusions may not apply to certain features.</p>
<p><strong>Example:</strong><br>
In VS Code and Visual Studio, exclusions do <strong>not apply</strong> when using:</p>
<pre class=" language-text"><code class="prism  language-text">@github
</code></pre>
<h2 id="semantic-information-leakage">2. Semantic Information Leakage</h2>
<p>Copilot may still receive:</p>
<ul>
<li>Type information</li>
<li>Symbol definitions</li>
<li>Hover metadata</li>
</ul>
<p>If this information is provided by <strong>non-excluded files</strong> that reference excluded content.</p>
<hr>
<h2 id="policy-scope-limitations">3. Policy Scope Limitations</h2>
<ul>
<li>Exclusions only apply to members of the <strong>configured organization</strong></li>
<li>External users or collaborators may still receive suggestions based on the same files</li>
</ul>

<h2 id="issue-1-—-code-suggestions-are-missing">Issue 1 — Code Suggestions Are Missing</h2>
<h3 id="possible-causes--fixes">Possible Causes &amp; Fixes</h3>
<ul>
<li>
<p><strong>Internet Connection</strong><br>
Ensure you have a stable internet connection. Copilot requires continuous access to GitHub servers.</p>
</li>
<li>
<p><strong>Outdated Extension</strong><br>
Update the GitHub Copilot extension to the latest version in your IDE.</p>
</li>
<li>
<p><strong>IDE Compatibility</strong><br>
Confirm your IDE supports Copilot and is properly configured.</p>
</li>
<li>
<p><strong>Content Exclusions</strong><br>
Check whether the file is excluded from Copilot analysis at the repository or organization level.</p>
</li>
</ul>

<h2 id="issue-2-—-content-exclusions-not-working-as-expected">Issue 2 — Content Exclusions Not Working as Expected</h2>
<h3 id="common-problems">Common Problems</h3>
<h3 id="delayed-application-of-exclusions">1. Delayed Application of Exclusions</h3>
<ul>
<li>Changes can take up to <strong>30 minutes</strong> to propagate to IDEs already running.</li>
<li>Reload Copilot or restart the IDE to apply changes immediately.</li>
</ul>
<h3 id="inadequate-scope-of-exclusions">2. Inadequate Scope of Exclusions</h3>
<ul>
<li>Exclusions only apply to members of the <strong>configured organization</strong>.</li>
<li>Ensure all relevant users are covered by the policy.</li>
</ul>
<h3 id="visual-indicator-in-ide">3. Visual Indicator in IDE</h3>
<ul>
<li>Look at the <strong>GitHub Copilot icon</strong> in the status bar.</li>
<li>A diagonal line through the icon means Copilot is disabled for the current file.</li>
<li>Hover over the icon to see whether the organization or repository enforced the exclusion.</li>
</ul>
<h3 id="ide-specific-limitations">4. IDE-Specific Limitations</h3>
<ul>
<li>Some features, like <strong>Copilot Chat</strong>, may ignore content exclusions in certain IDEs.</li>
<li>Adjust workflows accordingly when handling sensitive files.</li>
</ul>
